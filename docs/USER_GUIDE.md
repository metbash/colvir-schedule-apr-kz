## Как запустить

> ⚠️ **Важно:** Приложение использует ES-модули (`import/export`), поэтому **нельзя открывать `index.html` двойным кликом** — браузер заблокирует загрузку модулей (`file://` CORS-ошибка).

Необходим локальный HTTP-сервер. Варианты:

### Вариант 1 — VS Code + Live Server (рекомендуется)
1. Установи расширение **Live Server** в VS Code
2. Открой папку проекта в VS Code
3. Правой кнопкой по `index.html` → **Open with Live Server**
4. Автоматически откроется `http://127.0.0.1:5500`

### Вариант 2 — Python
```bash
# В папке проекта:
python -m http.server 8080
# Открой: http://localhost:8080
```

### Вариант 3 — Node.js
```bash
npx serve .
# Откроется автоматически
```

## Интерфейс

Приложение состоит из двух панелей:

| Панель | Содержимое |
|--------|------------|
| **Левая** | Форма ввода параметров займа + льготные периоды |
| **Правая** | График платежей + сводная статистика |

---

## Параметры займа

| Поле | Описание | Пример |
|------|----------|--------|
| **Сумма кредита** | Тело займа в тенге (KZT) | `230 575 460` |
| **Ставка, % годовых** | Годовая процентная ставка | `20` |
| **Срок, месяцев** | Количество периодов погашения | `12` |
| **Дата начала / выдачи** | Дата фактической выдачи займа | `25.06.2026` |
| **Дата первого платежа** | Дата первого планового платежа | `21.07.2026` |
| **Дата последнего платежа** | Дата финального платежа | `25.06.2027` |
| **Метод погашения** | Аннуитет или равные части ОД | `Аннуитет` |
| **Единоразовая комиссия, тг** | Комиссия за выдачу (влияет только на ГЭСВ, в графике не показывается) | `0` |

### Методы погашения

- **Аннуитет** — каждый платёж одинаковый. Большую часть в начале составляют проценты, в конце — основной долг.
- **Равные части ОД** — ОД делится поровну на все периоды. Платёж уменьшается каждый месяц.

## Льготные периоды

Льгота позволяет отсрочить выплату **основного долга (ОД)** и/или **процентов (%)** на N месяцев. Отложенная сумма перераспределяется на оставшиеся платежи.

### Режим «Простой»
1. Укажи количество льготных месяцев (например, `3`)
2. Отметь флаги: **ОД** и/или **%**
3. Нажми **«Применить льготу»**

Льгота автоматически применится к первым N периодам.

### Режим «По месяцам»
1. Нажми вкладку **«По месяцам»**
2. Нажми **«Заполнить периодами»** — появится список всех периодов
3. Вручную отмечай нужные периоды флажками ОД / %

### Распределение отложенного платежа

| Режим | Описание |
|-------|----------|
| **На все предстоящие платежи** | Отложенная сумма равномерно распределяется по всем будущим платежам |
| **На первый предстоящий платёж** | Вся отложенная сумма добавляется к ближайшему платежу |

### Сброс льготы
Нажми **«Сбросить»** в простом режиме или **«Очистить»** в ручном — льготы будут удалены.

## Расчёт графика

1. Заполни все параметры займа
2. При необходимости настрой льготные периоды
3. Нажми кнопку **«Рассчитать график»** (синяя кнопка внизу левой панели)

### Что отображается в таблице

| Столбец | Описание |
|---------|----------|
| **#** | Номер периода (0 = строка выдачи) |
| **Дата платежа** | Дата планового платежа (с учётом производственного календаря КЗ) |
| **Сумма платежа** | ОД + Вознаграждение |
| **Вознаграждение** | Начисленные проценты за период |
| **Основной долг** | Погашаемая часть тела займа |
| **Остаток ОД** | Остаток основного долга после платежа |
| **Кол-во дней** | Количество дней в периоде |
| **Тип** | Тип строки: `REGULAR`, `GRACE`, `ISSUE` |

### Цветовое обозначение строк

- 🟡 **Жёлтые строки** — льготные периоды (`GRACE`)
- ⬜ **Белые строки** — обычные платежи (`REGULAR`)
- 🔵 **Синие ячейки** — редактируемые поля

### Сводная информация (внизу)

После расчёта появляется 5 карточек:
- Общий ОД
- Общие проценты
- Общая сумма
- Строк графика
- **ГЭСВ** (Годовая Эффективная Ставка Вознаграждения) — выделена синим

---

## Редактирование строк

После расчёта ячейки **Дата платежа**, **Основной долг** и **Вознаграждение** доступны для ручного редактирования.

1. Кликни на синюю ячейку
2. Введи новое значение
3. Нажми `Enter` или кликни в другое место

Отредактированные ячейки выделяются **жёлтым** цветом. После редактирования появляется кнопка **«↺ Пересчитать ГЭСВ»**.

---

## Пересчёт ГЭСВ

Если ты вручную изменил даты или суммы платежей, нажми кнопку **«↺ Пересчитать ГЭСВ»** (оранжевая) — калькулятор пересчитает ГЭСВ с учётом новых значений.

> ГЭСВ в сводной таблице обновится автоматически.

## Экспорт в Excel

Нажми кнопку **«⬇ Экспорт в Excel»** (зелёная) — файл скачается автоматически.

### Формат файла

- Формат: `.xlsx` (Excel 2007+)
- Имя файла: `schedule_{сумма_в_тысячах}k_{дата}_{время}.xlsx`
  - Пример: `schedule_230575k_20260809_2340.xlsx`

### Что содержит файл

**Шапка (строки 1-7):**
- «График погашения займа» + дата формирования
- Сумма и валюта займа
- Ставка вознаграждения
- ГЭСВ
- Срок займа
- Метод погашения

**Таблица (с строки 9):**
- Дата платежа, Сумма платежа, Вознаграждение, Основной долг, Остаток ОД, Кол-во дней
- Строка «Итого» с суммами

**Стилизация:**
- Тёмно-синяя шапка таблицы с белым текстом
- Числовой формат `#,##0.00`
- Даты в формате `ДД.ММ.ГГГГ`
- Льготные периоды — жёлтый фон
- Итоговая строка — голубой фон, жирный шрифт

## Частые ошибки

| Проблема | Причина | Решение |
|----------|---------|--------|
| Кнопки не работают, ошибки в консоли `CORS` / `file://` | Файл открыт напрямую, без сервера | Используй Live Server или `python -m http.server` |
| `Failed to load resource: net::ERR_FAILED` | Аналогично — открытие через `file:///` | Запусти локальный сервер |
| График не рассчитывается, ошибка в красном поле | Некорректные параметры (дата, сумма) | Проверь даты и числовые значения |
| ГЭСВ = 0% | Не указана единоразовая комиссия или нет платежей | Это нормально если комиссия = 0; ГЭСВ = ставке займа |
