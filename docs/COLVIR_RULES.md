# COLVIR Schedule & APR Calculator (KZ)

## COLVIR RULES

Документ содержит подтвержденные правила работы Colvir.

Все правила должны подтверждаться реальными графиками Excel.

Статусы:

- CONFIRMED — подтверждено графиками.
- VERIFIED — подтверждено математически.
- IMPLEMENTED — реализовано в коде.
- TESTED — проходит автоматические тесты.

---

# RULE-001

Название

Техническая строка выдачи кредита.

Статус

CONFIRMED

Описание

Первая строка графика всегда соответствует выдаче кредита.

Дата = дата выдачи.

Платеж = 0.

Проценты = 0.

Основной долг = 0.

Не является платежом.

---

# RULE-002

Название

Льготный период по основному долгу.

Статус

CONFIRMED

Описание

Во время льготного периода:

Основной долг = 0.

Начисляются только проценты.

Остаток не уменьшается.

---

# RULE-003

Название

Последний платеж.

Статус

CONFIRMED

Описание

Последний платеж полностью закрывает остаток.

Допускается корректировка суммы платежа на копейки.

---

# RULE-004

Название

Типы графиков.

Статус

CONFIRMED

Описание

В имеющемся наборе графиков присутствуют:

- Аннуитет.
- Погашение равными долями.
- Льготный период.

---

# RULE-005

Название

Начисление процентов.

Статус

VERIFIED

Описание

Проценты рассчитываются по формуле:

Interest =
Balance × Rate × Days / 360

Используется фактическое количество дней.

Метод начисления:

Actual / 360.

Подтверждено расчетами loan_2.

---

# RULE-006

Название

Округление процентов.

Статус

VERIFIED

Описание

Проценты округляются до двух знаков после каждого периода.

Округление производится сразу после вычисления процентов.

---

# RULE-007

Название

Остаток.

Статус

CONFIRMED

Описание

Проценты начисляются на остаток на начало периода.

После платежа остаток уменьшается на сумму погашения основного долга.

---

# RULE-008

Название

Эталонные тестовые графики.

Статус

CONFIRMED

Описание

Эталонными считаются:

loan_1.xlsx

loan_2.xlsx

...

loan_10.xlsx

Все изменения движка должны проверяться на этих графиках.
