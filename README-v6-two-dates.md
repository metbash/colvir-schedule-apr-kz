# v6 — две даты графика

## Назначение

Ветка `v6` вводит раздельное хранение двух дат:

- `calculationDate` — расчётная/плановая дата периода, полученная из даты первого платежа и номера периода; может выпадать на выходной или праздник.
- `paymentDate` — фактическая дата платежа после применения календаря Colvir и переноса на рабочий день.

## Этапы v6

1. Сохранить обе даты в каждой строке графика.
2. Отображать обе даты в таблице и экспорте.
3. Сверить даты с эталонами Colvir.
4. Только после подтверждения определить, какая дата участвует в начислении вознаграждения.
5. Отдельно проверить аннуитет и равные доли.

## Важное ограничение

На первом этапе формулы вознаграждения и ГЭСВ не изменяются. Это диагностическая версия, чтобы не сломать уже совпавшие графики.

## Проверяемые кейсы

- Аннуитет без льготы.
- Аннуитет с льготой ОД.
- Равные доли без льготы.
- Равные доли с льготой.
- Ежеквартальный график.

Файлы с частичным досрочным погашением не используются для проверки.
